# goreecloud-music

GoreeCloud Music is GoreeCloud’s first-party, self-hosted-first, multi-user music platform, powered by the GoreeCloud Resonance capability system.

## Project documentation

- [Project specification mirror](docs/PROJECT-SPECIFICATION.md) — repository mirror of the authoritative Drive `Project Specification — Music.docx`.
- [Feature roadmap](FEATURE-ROADMAP.md) — current planned/recommended feature control.

## Status

Active development / repository initialization. Documentation in this repository distinguishes planned and proposed capabilities from verified implementation. A feature appearing in the specification or roadmap is **not** evidence that it has been implemented, validated, released, or accepted as Stable.

All GoreeCloud Music clients and services remain subject to applicable GoreeCloud requirements including current-Stable Glaze UI conformance, multi-user isolation, Wardveil Security, Privacy Shield, Everkeep, and verified release evidence.
