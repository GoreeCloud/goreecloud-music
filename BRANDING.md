# GoreeCloud Music — Branding

## Canonical identity

- **Product name:** GoreeCloud Music
- **Capability identity:** GoreeCloud Resonance
- **Preferred capability presentation:** GoreeCloud Music — Powered by Resonance
- **Repository:** `GoreeCloud/goreecloud-music`

GoreeCloud Music remains the application name. **Resonance** is the umbrella music capability identity and must not replace the GoreeCloud Music product identity or be shortened into a standalone product name where doing so would create ambiguity.

## Interface identity

All GoreeCloud-controlled Music graphical interfaces must use the latest approved Stable Glaze UI contract. The current Stable requirement is **GLAZE UI V1.4.1 / 1.4.1**. Product-specific music artwork, album art and optional provider identities may coexist with Glaze UI but must not override GoreeCloud product identity or accessibility requirements.

Source and availability indicators should be compact, readable and accessible. They must use iconography and text rather than color alone.

## Platform identities

- Security experiences use Wardveil Security where applicable.
- Privacy authorization and controls use Privacy Shield where applicable.
- Continuity and recovery use Everkeep where applicable.
- Cross-service coordination uses GoreeCloud Mesh where applicable.
- Account and session integration uses GoreeCloud Identity where applicable.

Provider branding must remain subordinate to GoreeCloud Music and must accurately indicate external-source boundaries.
